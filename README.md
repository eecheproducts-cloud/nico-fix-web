# Nico Fix, website

One-page bilingual (EN/ES) site for Nico Fix, static HTML/CSS/JS, deployed on GitHub Pages at [nicofix.nl](https://nicofix.nl).

## Run locally

ES modules need an actual HTTP server (not `file://`):

    python -m http.server 8000

Then open http://localhost:8000

## Run tests

    npm test

## Service pages (SEO)

One static page per service, in English (`/painting/`, ...) and Spanish (`/es/pintura/`, ...), plus `sitemap.xml`, are generated by a script. Edit the copy in `scripts/landings-data.mjs`, then run:

    node scripts/build-landings.mjs

There are no pages per city on purpose: pages that only swap the city name count as doorway pages for Google. Cities are listed on each service page and in the Google Business Profile. If a new page is added to the site, add it to the sitemap section of `scripts/build-landings.mjs`, since the script rewrites `sitemap.xml`.
